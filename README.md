# credit-strategy-diff

Сервис для аналитиков скоринга: прогоняет исторические заявки через старую и новую
версию кредитной стратегии и показывает, что изменилось, кого затронуло и почему.

Задача от «Баланс-платформы» для хакатона (6–8 ноября, НИЯУ МИФИ).

## Идея

Стратегия = версионируемый набор правил + скоринговая модель. Приложение:

1. загружает две версии стратегии и набор исторических заявок,
2. прогоняет заявки через обе версии параллельно (движок),
3. сравнивает решения по каждой заявке и объясняет разницу (дифф),
4. агрегирует: матрица миграций, approval rate, срезы по сегментам (аналитика),
5. показывает отчёт с drill-down до причины изменения для конкретной заявки (фронт).
