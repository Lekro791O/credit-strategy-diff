`rules[].hit = null` означает, что правило не вычислялось; `false` означает, что оно вычислено и не сработало. Поэтому переход `null → false` считается изменением значения: аналитик видит переход между разными состояниями вычисления. Нормализация записывает JSON null как строку `NULL` с типом `null`, а boolean false — как строку `false` с типом `boolean`; отсутствующий атрибут обрабатывается отдельно. Сравнение различает типы и не приравнивает JSON null к строке `"NULL"`. Наблюдение изменения не доказывает его причинную связь с решением.
